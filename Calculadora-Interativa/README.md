# Java Calculator

Calculadora desenvolvida em Java para praticar lógica de programação e conceitos fundamentais da linguagem.

## Funcionalidades

- Soma
- Subtração
- Multiplicação
- Divisão
- Operações com números decimais
- Validação de divisão por zero
- Menu interativo para realizar múltiplos cálculos

## Conceitos praticados

- Classes e métodos
- Parâmetros e retornos
- Scanner
- Switch/Case
- If/Else
- Do/While
- Organização de código em diferentes classes

## Como executar

Compile os arquivos:

```bash
javac Main.java Calculadora.java
```

Execute:

```bash
java Main
```

Projeto desenvolvido como parte dos meus estudos em Java.
