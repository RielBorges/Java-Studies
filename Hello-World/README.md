# Hello World - Java

Meu primeiro programa desenvolvido em Java, criado como parte dos meus estudos de programação.

## Objetivo

Praticar os primeiros conceitos da linguagem Java e entender a estrutura básica de um programa.

## Conceitos praticados

- Estrutura básica de uma classe Java
- Método `main()`
- Saída de dados com `System.out.println()`
- Sintaxe básica da linguagem

## Código

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello World!");
    }
}
```

## Como executar

Compile o arquivo:

```bash
javac Main.java
```

Execute:

```bash
java Main
```

## Resultado esperado

```text
Hello World!
```
